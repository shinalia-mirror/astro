# 帆型市立大学・研究論文データベース

GitHub Pagesで公開できる静的サイトです。

## 使い方
1. `index.html`、`style.css`、`script.js` の3ファイルを同じフォルダに置く。
2. `index.html` を開けばローカルでも動作します。
3. GitHub Pagesでリポジトリを公開すると、そのままURLからアクセスできます。
